# Experimental Protocol

## Objective

The project compares discrete and continuous-time models for in-hospital mortality prediction on PhysioNet/CinC Challenge 2012 while keeping model selection separate from retrospective B/C scoring.

## Development boundary

Set A is the only source of labels used for development decisions.

For the main benchmark:

- random seed: `42`
- development split: stratified 80/20 Set A
- optimizer: Adam
- learning rate: `1e-3`
- batch size: `128`
- maximum epochs: `30`
- early-stopping patience: `6`
- epoch-selection metric: validation AUPRC
- gradient clipping: `5.0`

Vocabulary and normalization statistics are fitted on the Set-A training partition during development. The Event-1 threshold is also selected on the Set-A validation partition.

After epoch count and threshold are fixed, preprocessing statistics are refitted on all Set A and the model is retrained on all Set A for the selected number of epochs.

## Frozen selections

| Model | Selected epochs | Event-1 threshold |
|---|---:|---:|
| Persistence baseline | 8 | 0.2551 |
| GRU | 11 | 0.2571 |
| GRU-D | 7 | 0.3300 |
| Latent ODE | 11 | 0.2919 |
| Neural CDE | 4 | 0.2481 |

The Latent ODE uses latent dimension 16, hidden dimension 64 and `dopri5`. Its total loss is BCE + `0.1 × reconstruction` + `1e-3 × KL`.

The Neural CDE uses 32 hidden channels, hidden dimension 64, Hermite cubic interpolation with backward differences, RK4 and step size 1 hour.

## Information boundary for B/C

Set B and Set C records are loaded without outcomes. Risk scores are generated first and frozen. Only after prediction are `Outcomes-b.txt` and `Outcomes-c.txt` read and aligned by `RecordID`.

This reproduces the intended development/test information boundary as closely as possible with the now-public data.

The results remain a **retrospective historical benchmark**, not a new Challenge submission. The original competition allowed interaction with Set B and used Set C for final ranking, and the public outcomes are now available. No official leaderboard rank is claimed.

The GRU is selected as the final deployed architecture because it leads the benchmark in AUROC, AUPRC and Event 1 on Set C. GRU-D's lower Event-2 score is evidence that calibration and discrimination are separate objectives.

## Controlled timestamp ablation

Notebook 05 compares hourly and exact-time representations under a controlled Latent-ODE architecture and optimization setup.

Set-C discrimination:

| Representation | AUROC | AUPRC |
|---|---:|---:|
| Hourly controlled | **0.8474** | **0.4974** |
| Exact-time controlled | 0.7863 | 0.3834 |

The exact-time representation does not improve this configuration. This result is specific to the controlled architecture and should not be generalized to all continuous-time models.

## Final artifact

The final production-like artifact is generated by:

```bash
python -m src.training.finalize_gru
```

It retrains the selected GRU on all Set A using:

```text
seed      = 42
epochs    = 11
hidden    = 64
batch     = 128
lr        = 0.001
threshold = 0.2571
```

The serialized bundle contains the state dictionary, vocabulary, static-variable order, normalization statistics, architecture configuration and threshold.

The exported score is not presented as a calibrated mortality probability.
